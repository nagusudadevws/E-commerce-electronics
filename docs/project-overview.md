# Multi-Vendor E-Commerce Platform - Project Overview

## Project Context

This is a multi-vendor e-commerce platform specializing in Electronics & IoT devices. The project is divided into 6 sequential development phases, each building upon the previous phase.

## Quick Reference

### Tech Stack
- **Frontend**: Next.js (TypeScript, Tailwind CSS)
- **Backend**: FastAPI (Python) - for payments and media uploads
- **Database & Auth**: Supabase (PostgreSQL)
- **Hosting**: Vercel (Frontend)

### Development Phases
0. **Phase 0**: Landing Page & Public Interface
1. **Phase 1**: Project Setup & Authentication Foundation
2. **Phase 2**: Database Schema & Core Models
3. **Phase 3**: Admin Dashboard & Product Management
4. **Phase 4**: Order Management System
5. **Phase 5**: Customer Management & Product Catalog
6. **Phase 6**: Payment Gateway Integration & Media Upload

### Key Files Location
- **Development Phases**: `/development-phases/`
- **PRD Document**: `/multi_vendor_ecommerce_prd.md`
- **Context/Reference**: `/context/`

### User Roles
- **Admin**: Full system control
- **Seller (Vendor)**: Manage own products and orders
- **Customer**: Browse products and place orders
